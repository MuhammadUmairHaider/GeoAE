Built 2026-09-26 because every earlier intervention fit directions from LABELLED concepts; this is the first test of the 2000 clusters themselves as handles. User's hypothesis: better-separated unsupervised clusters are more controllable; the open "real challenge" is interpretability (encoder ties matched k-means on label alignment — [[token-bypass-design-b]]).

Design: L27 = last block, so next-token dist = softmax(lm_head(norm(h))) — no forward pass, dump rows only. Signature P_k = mean next-token dist of cluster k's members on even-doc held-out rows; sources from odd docs. Edit = translation z + a(c_t − c_s) (AE, decoded, bypass adds b[tok]); ae_h = AE partition's member means edited in base space (separates "better partition" from "better edit space"); km = x + a(C_t − C_s) (b / projection cancel in a gap). Metrics: transfer (JS to target < JS to source), specificity (vs random third cluster, chance .5), gain, disruption KL(p'||p_ref), move ||dh||/||h||. Compare at MATCHED move and MATCHED disruption (arms differ ~35% in disruption per unit move), doc-bootstrap CIs. Hubs (>3x uniform usage) excluded by default — bypass has more hub rows, so run_cluster_steering.sh also runs --hub_x 1e9.

Preliminary (smoke, 30k ref rows, 600 sources — noisy): at matched KL 0.1/0.5, transfer bypass ae .18/.28, bypass ae_h .21/.35, parent .07/.16, km_new .07/.16; km_tokmean (matched encoder-free) at move .2: .14 vs bypass .25, specificity below chance. I.e. bypass clusters ~2x better handles, and better than matched k-means — the first place the encoder beats its matched control. Full run: eval_out/run_cluster_steering.sh.

**FULL RESULT (2026-09-26, 250k ref rows, 20k sources/arm, doc-bootstrap CIs ±~0.005; eval_out/cluster_steering{,_allhubs}.json):** transfer at MATCHED DISRUPTION KL 0.1 / 0.5 / 1.0 — parent ae .036/.103/.192, km_new .035/.103/.192 (identical: parent encoder adds nothing as a handle), km_tokmean .062/.133/.217, km_tok64 .062/.106/.162, bypass ae .085/.161/.240, bypass ae_h (AE partition edited in base) .087/.172/.275. Specificity: parent/km_new .55/.63/.70; bypass ae lower (.53/.60/.64) but ae_h recovers (.55/.63/.71); km_tokmean .53/.60/.64. => bypass clusters beat parent (~2.4x at KL .1), raw k-means AND the matched encoder-free km_tokmean (+.02–.06, CIs separated) — first encoder win over its matched control; the win lives in the PARTITION (ae_h ≥ ae). Same ordering with no hub exclusion. km_tok64 (best for label alignment) is the worst handle. Matched-move tables favour parent at large moves only because parent disrupts ~1.6x more per unit move — use matched disruption. Caveat kept: one row, next-token only (L27 last block); generation-level test is the next step.

**Generation-level version (built 2026-09-26):** geoae/interp/cluster_steer_generate.py + cluster_steer_judge.py, sheet eval_out/run_cluster_steer_generate.sh. Base (km_new) vs bypass only. Partition steering at every position: h += a (m_t − m_s(pos)), member means from held-out even docs — identical form, only the partition differs. 40 random content targets/codebook (same rule: non-hub, >=50 members, top-30 lift tokens mostly words), 20 neutral prompts, greedy 32 tokens. alpha >= 1 degenerates text (ppl x3.5–7.6, 'aircraft aircraft…'), so the grid is 0.1–1.0 with an alpha-0 chance anchor; compare at matched perplexity. Automatic forced choice (4-way, cluster next-token log-lift) is partly circular; the LLM judge (OpenRouter gemini-2.5-flash-lite, profiles = raises-next words + member tokens, ~9.6k cached calls) is the independent check. Smoke (8 targets): at matched ppl base ≈ bypass on the automatic score; bypass text degenerates much less per alpha (9% vs 38% at a0.5).

**GENERATION RESULT (2026-09-26, 40 targets x 20 prompts, LLM judge gemini-2.5-flash-lite, 9.6k calls): TIE — the single-row advantage does NOT carry to generated text.** LLM-judged hit (chance .25) at matched perplexity x1.1/1.25/1.5: base .300/.300/.330 vs bypass .276/.291/.318; at matched degeneracy .10/.20/.30/.50: base .300/.310/.342/.405 vs bypass .253/.312/.355/.442 — all CIs overlap. Automatic (circular) score favours base (.405 vs .327 at ppl x1.1). Both are WEAK: fluent steering reaches only ~30/100 (chance 25); content appears only as text degenerates. Traps: perplexity FALLS for degenerate repetition ('the the the', base a1.0 ppl x1.41 at 95% degenerate) — use degeneracy as a second fluency axis; judge profiles are word lists, which favour lexical (token-shaped) base clusters over context-defined bypass clusters. Bypass steering keeps text more fluent per alpha (degenerate 25% vs 51% at a0.5).

**v2 (2026-09-26, whole-word targets from >=20 docs; eval_out/cluster_steer_{generate,judge}_v2.json).** Manual blind check first (me vs LLM judge agreed 14/16; v1's filter let mid-word fragment clusters in as unjudgeable targets). **Blind human audit of v2 text (subagent, 360 items, 2026-09-26; scratchpad agent_audit/):** fluent on-target text is RARE — 3/180 base vs 17/180 bypass (2 of those generic attractors: 'not yet vaccinated…' appears for 23/40 bypass targets on one prompt). Judge is valid on real control (hit 14/14 of human-T) but its raw rate = 25% chance + per-cell priors (41/84 chance hits were cells already hit at alpha 0) + target-word LOOPS counted as hits (22/28; 'die die die', 'September September'). Non-content targets despite the filter: base ~23/40, bypass ~12–15/40.
**Correct scoring (now in cluster_steer_judge.py 'net_fluent'): fluent continuations only (distinct2 >= .6), net of the same cell's alpha-0 hit; usable = fluent share x net.** v2: net per fluent continuation EQUAL (a0.5 base +13–16 vs bypass +16–17), fluent share differs (a0.5 49% vs 79%; a0.75 12% vs 51%) → usable on-target per 100 attempts best-alpha base ~6.5 (a0.3) vs bypass ~15 (a0.75). Two independent judge passes agree. Mechanism (user asked 'is it concept quality?'): yes — bypass partition has more topic clusters, and its member means average over many tokens so the steering gap carries context, not one token's identity; base token-shaped clusters make the model emit that token → loops.

**Open limitation (user, 2026-09-26): the 2x win is shown only on each arm's OWN discovered clusters** (different targets per arm → target-difficulty confound: bypass targets are more often broad topics, easier to steer fluently). On NAMED concepts bypass z ≈ base h: DB14 st_range_a1 target/collateral 0.86/0.24 → 0.90/0.20 (+.079*), bios parity, number tie; atlas concept alignment below base k-means. Label directions (class-mean gaps) already average over many tokens, so the partition's anti-token advantage has nothing to act on. Bridge test proposed: same named targets for both arms (concept → enriched clusters → steer, vs label direction), generation + judge on concept names.
