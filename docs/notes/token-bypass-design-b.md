Built 2026-09-25 after the token-erasure k-means result ([[token-erasure-option2]]); Tokenized-SAE-style per-token bias, but subtracted BEFORE the encoder too (a decoder-only bias would leave clusters token-shaped). Only the CURRENT token is bypassed — a predicted-next bypass is computed from the unedited h and would pull latent edits back.

Code: geoae/token_bias.py (table = shrunk means n/(n+30), tokens >=10 train rows: 49.7k tokens, 98.5% of rows, ~305 MB fp16); GeoAE(token_bias_rows, vocab_size) buffers tb_index/tb_table + encode/decode/forward(x, tok); ActivationBuffer(return_tokens) + data.split_batch; hooks.TokenIdTap (embedding pre-hook → ids for splice fns, row-aligned with hs.reshape(B*T)); neuronlens.make_z_gate(tap=). load_ae_checkpoint refuses bypass ckpts unless allow_token_bias=True — converted: concept_probe, probe_chance_corrected, clustering_quality, mmlu_splice, token_structure, closest_tokens, steering_concept_compare, range_intervention_compare, range_number_control (2026-09-25: capture_h(return_ids=True), make_z_steer/make_z_edit/make_last_patch take tap=; latent DELTAS still decode with ae.decoder — bias cancels). NOT converted (refuses): causal_concept_compare. Intervention sheet: eval_out/run_tokbias_interventions.sh + summarize_tokbias_interventions.py (head-to-head vs d6144_new, number via noun bootstrap).

Probe caches: the 09-01 sequence caches are NOT reproducible (old streaming shuffle; only sentiment_long matched) → cache_ids/ rebuilt with last_token_id, token rungs symlinked; all arms re-scored there.

Baseline (200k held-out rows): share of clusters that are pure current-token detectors (top token >= 80%): d6144_new 19.9%, km_new 10.6%, km_tok64 5.9% — the AE is MORE token-driven than encoder-free k-means. cNMI(cluster, cur token) .387 / .296 / .181.

**Bootstrap trap:** NMI on with-replacement resamples is biased UP, more for arms spreading small rungs over many clusters (atlas), so raw percentile CIs can exclude their own point estimate. All summaries now use centred (basic) intervals: m + quantile(boots − mean(boots)). Never report mean(boots) as the estimate.
