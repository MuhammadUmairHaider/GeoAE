# History

This directory preserves dated research notes, audits, chat references and migration evidence. Commands and scheduler states inside historical prose describe their original context. Use [current usage](../usage.md), [research state](../research.md), and the [experiment index](../../experiments/README.md) for maintained entry points.

- [Chat index](CHAT_HISTORY.md): main and helper transcripts and import limitations.
- [Migration status](migration/LAPTOP_SETUP_STATUS.md) and [handoff](migration/LAPTOP_HANDOFF.md): recovered workspace and cluster paths.
- [Project memory](notes/MEMORY.md): scientific background and pitfalls; check saved results before citing numbers.
- [Cleanup proposal](audits/CODEBASE_CLEANUP_PLAN.md) and relocation ledgers: original layout and implementation provenance.

The original workspace and removed historical tools remain outside the source checkout, indexed by [the artifact catalog](../artifacts.json). Historical result files, source archives and manifests were preserved rather than rewritten to the new layout.
